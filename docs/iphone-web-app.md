# IRON LOG on iPhone

Open the deployed HTTPS website in Safari, use Share > Add to Home Screen, enable Open as Web App if offered, and tap Add. Launch IRON LOG from its Home Screen icon. No TestFlight or Apple Developer subscription is needed for this web distribution.

The app includes a standalone web manifest, Apple Home Screen icon, and safe-area spacing. On small screens navigation wraps, list tables become cards, and workout sets use a two-column form. The page scrolls normally; an open dialog uses its own vertical scroll while the background is locked.

This configuration does not provide offline operation. Login and API features still need a network connection. Home Screen storage can be separate from Safari storage, so users may need to sign in again. Verify installation, keyboard, safe-area spacing, and scrolling on a physical iPhone after deployment.
