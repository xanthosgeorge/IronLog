# Mobile screenshots

These unmodified PNG screenshots were captured from the running IronLog Flutter
app on the Pixel 9 Pro XL Android emulator. They show the Greek interface with
the orange/gray accent palette and training history loaded from the Azure API.

| File | Screen |
| --- | --- |
| [android-progress.png](android-progress.png) | Exercise selection, reps chart, first/latest values, and improvement |
| [android-exercises.png](android-exercises.png) | Exercise catalog with search, filters, and create/edit/delete controls |
| [android-workouts.png](android-workouts.png) | Workout history with dates, duration, and training volume |

The captures contain no account identifiers, passwords, or access tokens.
To refresh them, navigate to the appropriate screen and use Android's
`adb shell screencap -p` followed by `adb pull`. Keep profile/account screens and credentials
out of documentation images. Do not alter training records just to take screenshots.

See the [main README](../../README.md#screenshots) for the image gallery.
